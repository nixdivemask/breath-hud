# Security

Breath HUD is a **local visualization**. It does not send video or cluster metrics to a server.

- Do not treat this repository, GitHub Issues, or chat logs as a place to paste identifiable shelter-resident information.
- Screen capture can include whatever is on the chosen display. Prefer capturing the camera-wall monitor, not a staff workstation with EHR / case-management windows.
- This software is **not a medical device** and is provided **without warranty**. It must not be the sole overdose-detection method in a site protocol.

Report vulnerabilities that would leak captured frames or stored cluster JSON off-box via GitHub Security Advisories on this repo.
